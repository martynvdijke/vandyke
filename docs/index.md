# vanDyke

The modern vanDyke misspelling ledger: a Go + SQLite backend with an HTMX front
end, a JSON API, an admin ledger with local/OIDC login and configurable
self-hosted Umami analytics. Entries support photos with clean public
derivatives, partial FTS5 search and stable `/e/{id}` permalinks.
